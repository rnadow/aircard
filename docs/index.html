What changed

为 iOS 26.4 补齐的关键路径

01 / PROBE

安全兼容性探针

在 Caches 下写入随机 canary，经 AirTraffic 回读并逐字节验证，最后清理。探针本身不修改 Wallet。

02 / PAIRING

配对文件导入

当开发者模式没有弹出授权入口时，可导入可信的 .plist、.mobiledevicepairing 或 .mobilepair。

03 / FOCUS

当前卡精准识别

打开 Wallet 中的目标卡，等待绿色 CURRENT CARD。只有该卡会被选中，适用于多卡场景。

10-card workflow

10 张卡，也能明确选中哪一张

开始扫描

在 AirCard 打开 Wallet 卡片扫描，不要仅按扫描顺序猜测卡片。

点开真正的目标卡

切换到 Wallet，点进想换卡面的那张卡，让它成为前台焦点。

等待 CURRENT CARD

回到 AirCard，等唯一目标出现绿色标记并被自动单选。

本地命名并单卡写入

用银行名和尾号四位备注，分配图片，只 Flash 这一张卡。

Windows → macOS runner

在 Windows 发起 IPA 构建

Windows 负责提交源码与取回产物，GitHub Actions 的 macOS Runner 负责调用 Apple 工具链。下载完成后脚本会核对 SHA-256。

注意：.p12 是签名证书，不是配对文件。配对记录、证书、UDID、卡片哈希和完整日志均不得公开提交。
# 首次安装并登录
winget install --id GitHub.cli
gh auth login

# 在源码目录运行
powershell -ExecutionPolicy Bypass `
  -File .\build-from-windows.ps1 `
  -Repository "rnadow/aircard"

# 输出
build/AirCard-iOS.ipa
build/AirCard-iOS.ipa.sha256
Boundaries

它会改什么，不会改什么

  • 会：修改设备上的本地视觉缓存。
  • 不会：修改支付凭据、余额、发卡行记录或 Secure Element。
  • 建议：先通过探针，再用一张卡和可替换图片测试。
  • 限制：实验版本不保证适配所有设备与系统构建。
